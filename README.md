# Employee Manager

A simple employee management program built with Python.

## About

This project is a beginner Python project designed to practice core programming concepts by building a small interactive employee management system.

## Current Features

* Display all employees
* Search for an employee by name
* Add a new employee
* Interactive menu
* Handle employees stored as dictionaries
* Use functions to organize the program
* Use loops and conditional logic

## Technologies
